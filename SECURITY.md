# Security policy

Security fixes are provided for the latest 3.0.x release of this fork.

Do not disclose a vulnerability in a public issue. This repository does not
enable GitHub's private vulnerability reporting, so open a minimal issue that
says a vulnerability exists — without details, impact or reproduction steps —
and ask the maintainer for a private channel. Details go there.

Remove credentials, personal data and customer data from every report. Include
the affected plugin and Redmine versions, and the reproduction steps once you
are on a private channel.

For the upstream project this fork derives from, see
[`redmineservices/redmine_status_history`](https://github.com/redmineservices/redmine_status_history).
